# devffin ScriptKit

A collection of scripts made in **Batch** for differents utilities such as :
- Scan my disk for corruption (diskscan.bat)
- Defragment my disk (defragdisk.bat)
- Clean my disk (cleandisk.bat)
- Compact my OS to save space (compactos.bat)
- Delete temporary files (deltempfiles.bat)
- Scan my disk for viruses (viruscan.bat)
- Quickly update all my apps (updateapps.bat)
- And much more...

> I create scripts when I have little time to spend on other things (about 2% of my week).
> If you can help me, if you have time, feel free to contribute to this repository.
